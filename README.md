# Git Workflow Demo

用于练习 Git 远程仓库、分支、Pull Request、代码评审和合并流程的小项目。

## 参与角色

- A（仓库所有者、评审者）：liyubo0713

## 当前功能

- 加法：`add(a, b)`
- 减法：`subtract(a, b)`

## 运行方式

需要 Python 3，无需安装第三方依赖。

```powershell
python calculator.py
```

预期输出：

```text
2 + 3 = 5
5 - 3 = 2
```
